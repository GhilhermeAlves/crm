## Objetivo

Definir o escopo da versão 1.0 do CRM.

## Descrição

v1.0 é a versão de lançamento público. Expande o MVP com funcionalidades de automação, campanhas e multi-canal.

## Features

### Novas Features

| Feature | Descrição | Prioridade |
|---|---|---|
| Campanhas | Envio em massa WhatsApp/Email | P0 |
| Automações | Workflows básicos | P0 |
| Email integration | Envio/recebimento de email | P0 |
| Relatórios | Relatórios de vendas e chat | P0 |
| Templates aprovados | WhatsApp template management | P1 |
| IA básica | Sugestão de respostas | P1 |
| Multi-canal | WhatsApp + Email unificado | P1 |
| API pública | REST API para integrações | P1 |
| Billing | Assinatura e pagamentos | P1 |

### Melhorias

| Feature | Descrição |
|---|---|
| Dashboard avançado | Gráficos, filtros, comparativo |
| Kanban avançado | Drag-and-drop, métricas por coluna |
| Chat avançado | Transferência, quick replies |
| Busca global | Cmd+K search |
