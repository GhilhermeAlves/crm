## Objetivo

Documentar o roadmap do produto em fases, desde o MVP até a visão de longo prazo.

## Descrição

O roadmap define as funcionalidades e prioridades para cada versão do produto. É um documento vivo que é revisado trimestralmente.

## Regras

- MVP deve ser entregue em 3 meses
- Cada versão maior (v1, v2, v3) deve ter 6-12 meses
- Features são priorizadas por impacto e esforço
- Roadmap é revisado trimestralmente
