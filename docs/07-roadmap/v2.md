## Objetivo

Definir o escopo da versão 2.0 do CRM.

## Descrição

v2.0 foca em escala, IA avançada, mobile e enterprise features.

| Feature | Descrição | Prioridade |
|---|---|---|
| App mobile | React Native (iOS/Android) | P0 |
| IA avançada | Chatbot autônomo, scoring preditivo | P0 |
| White-label | Customização por empresa | P0 |

| Multi-idioma | i18n completo | P1 |
| Marketplace | Integrações de terceiros | P1 |
| Voice AI | Chamadas com IA | P1 |
