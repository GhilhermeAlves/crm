## Objetivo

Esta pasta concentra toda a documentação fundacional do projeto. Cada arquivo aqui é considerado **Single Source of Truth** para sua respectiva área. Qualquer mudança arquitetural ou de direção do produto deve ser registrada nestes documentos antes de ser implementada.

## Regra

> Nenhum código será escrito antes que toda documentação desta pasta esteja aprovada e consistente entre si.

## Responsabilidades

- Definir a identidade e o propósito do produto
- Registrar padrões e convenções obrigatórias
- Documentar decisões arquiteturais e seus impactos
- Servir de referência para todas as outras pastas de documentação

## Dependências

- Nenhuma. Esta é a camada mais fundamental da documentação.
