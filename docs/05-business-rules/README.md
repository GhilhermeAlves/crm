## Objetivo

Documentar todas as regras de negócio do CRM SaaS Omnichannel.

## Descrição

Regras de negócio são as regras que governam como o sistema opera. Elas são independentes de implementação e devem ser compreendidas por toda a equipe.

## Regras

- Toda regra deve ter justificativa
- Regras podem ser suspensas por decisão (ADR)
- Regras são revisadas trimestralmente
