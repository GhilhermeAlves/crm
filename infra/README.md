# Infrastructure

This directory contains infrastructure-as-code (IaC) configurations for the CRM SaaS Omnichannel project.

## Future Implementations

- Terraform/Pulumi for cloud resource provisioning
- Kubernetes manifests for container orchestration
- Helm charts for deployment configuration
- Monitoring and alerting configurations

## Cloud Provider

- **AWS** (planned)
  - ECS/EKS for container orchestration
  - RDS for PostgreSQL
  - ElastiCache for Redis
  - AmazonMQ for RabbitMQ
  - S3 for file storage

## Current Status

This directory is a placeholder for future infrastructure configurations. For local development and testing, use the Docker configurations in the `docker/` directory.
